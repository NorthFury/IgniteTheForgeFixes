# Requirements
Download [melon loader](https://melonwiki.xyz/#/?id=automated-installation) and install `0.7.3` for `Blacksmith: Ignite the forge`.

# How to build
Edit `IgniteTheForgeFixes.csproj` to point to your install location for the game.
I recommend selecting the Release build instead of debug.
Building the solution will copy the dll file directly in the correct location so you can use when you start the game.
